# Сайт ППР ПРО — 220 страниц

Сайт по разработке проектов производства работ (ППР, ППРк, ПОС, технологические карты, ордера ОАТИ) для Москвы и области.

## 👉 Открыть сайт

**https://jokerfrombali.github.io/ppr-pro-site/**

## Что в репозитории

| Папка | Что это |
|---|---|
| корень репозитория | Копия сайта для GitHub Pages — её и открывает ссылка выше |
| `production/` | **Сборка для боевого хостинга pprpro.ru.** Её заливаем в корень сайта целиком, включая скрытый `.htaccess` |
| `source/` | Исходники генератора: тексты, шаблоны, стили. Отсюда собираются обе версии |

## Важно про эту копию

GitHub Pages отдаёт только статические файлы, PHP там не работает. Поэтому **на этой копии формы ничего не отправляют** — кнопка просто открывает страницу «Заявка отправлена». Это витрина для изучения сайта.

Рабочие формы — в `production/`: там форма отправляется в `send.php`, который шлёт письмо и дублирует заявку в `zayavki.log`.

## Публикация на pprpro.ru

1. Залить содержимое `production/` в корень сайта, включая скрытый `.htaccess`.
2. Проверить, что на хостинге включён PHP.
3. В `send.php` проверить `$TO` и `$FROM` — адрес отправителя должен быть на вашем домене, иначе письма уйдут в спам.
4. Отправить тестовую заявку.
5. В Яндекс Вебмастере подтвердить регион «Москва» и отправить `sitemap.xml` на переобход.
6. Редиректы со старых `.html`-адресов уже прописаны в `.htaccess` — 24 правила.

## Перед публикацией заполнить

В `source/content/company.py` есть поля с пометкой «ПРОВЕРИТЬ» — их нельзя было придумывать:

- год начала работы и число выполненных проектов;
- номер СРО, ИНН, ОГРН;
- номер счётчика Яндекс Метрики;
- отзывы (`REVIEWS`) и кейсы (`CASES`).

Пока они пустые, страницы не врут: `/otzyvy/` объясняет, что публикуются только отзывы с согласия клиентов, `/portfolio/` показывает направления и типы объектов, реквизиты «направим по запросу».

Цена «от 30 000 ₽» и срок «от 3 дней» взяты с действующего сайта pprpro.ru — это факт, а не выдумка.

## Пересборка

```bash
cd source

# боевая версия для pprpro.ru
python3 build.py                    # → source/dist/

# версия для GitHub Pages (ссылки с префиксом, формы без PHP)
OUT=dist-pages BASE=/ppr-pro-site SITE=https://jokerfrombali.github.io \
FORM_ACTION=/spasibo/ FORM_METHOD=get python3 build.py

# посмотреть локально
cd dist && python3 -m http.server 8899   # http://127.0.0.1:8899/
```

Чтобы добавить страницу — допишите запись в соответствующий файл `source/content/kb_*.py` и пересоберите. Страница сама появится в навигации, карте сайта и `sitemap.xml`.
