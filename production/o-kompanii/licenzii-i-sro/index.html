Нужна ли лицензия на разработку ППР

Отдельного лицензируемого вида деятельности «разработка проектов производства работ» в законодательстве нет. Проект производства работ — организационно-технологический документ подрядчика, а не проектная документация в смысле Градостроительного кодекса.

Поэтому лицензия для его разработки не требуется. Требования возникают в двух других местах:

  • к подрядчику — для выполнения самих строительных работ на объектах, где это установлено законом, требуется членство в СРО;
  • по договору — отдельные заказчики включают в договор требование о наличии СРО или подтверждённой квалификации у разработчика ППР.

Если у вашего заказчика есть такое требование — пришлите формулировку из договора, подготовим необходимые документы.

Частые вопросы

Нужно ли СРО для разработки ППР?

Нормативного требования о членстве в СРО именно для разработки ППР нет. Требование может быть установлено договором с заказчиком.

Кто отвечает за решения в проекте?

Ответственность за производство работ несёт организация, утвердившая ППР. Разработчик отвечает перед заказчиком по договору: подробнее.

Предоставляете ли вы документы для тендера?

Да, подготовим комплект под требования закупочной документации. Уточните перечень.
