# Сайт ППР ПРО — исходники и сборка

Статический сайт на 220 страниц, генерируется из Python-шаблонов. Готовые файлы — в `dist/`.

## Быстрый старт

```bash
cd "/Users/macbookm4/Desktop/ППР/site"
python3 build.py          # пересобрать сайт в dist/
cd dist && python3 -m http.server 8899   # посмотреть локально: http://127.0.0.1:8899/
```

## Что где лежит

| Путь | Что это |
|---|---|
| `dist/` | **Готовый сайт.** Его и заливаем на хостинг целиком, в корень |
| `content/company.py` | Телефоны, почта, адрес, цена «от», срок «от», отзывы, кейсы. **Правится в первую очередь** |
| `content/kb_ppr.py` | 27 категорий и 111 видов работ раздела `/ppr/` |
| `content/kb_pprk.py` | Раздел `/pprk/` — краны и подъёмные сооружения |
| `content/kb_oati.py` | Раздел `/oati/` — ордера ОАТИ |
| `content/kb_uslugi.py` | Раздел `/uslugi/` — ПОС, ПОД, ТК, стройгенплан, ППГР |
| `content/kb_dlya.py` | Раздел `/ppr-dlya/` — корпоративные стандарты заказчиков |
| `content/kb_blog.py` | Блог, 20 статей |
| `content/kb_trust.py` | Главная, цены, калькулятор, примеры, о компании, контакты, юридические страницы |
| `engine.py` | Каркас страницы: шапка, подвал, формы, микроразметка |
| `render_ppr.py` | Шаблоны страниц услуг и статей |
| `redirects.py` | Карта 301-редиректов со старых `.html`-адресов |
| `assets/style.css` | Единственный файл стилей, без внешних зависимостей |
| `static/send.php` | Обработчик форм заявок |

## Публикация

1. Залить содержимое `dist/` в корень сайта (включая скрытый `.htaccess`).
2. Проверить, что PHP на хостинге включён — иначе формы работать не будут.
3. Открыть `send.php` и проверить адреса `$TO` и `$FROM`. `$FROM` должен быть на вашем домене, иначе письма попадут в спам.
4. Отправить тестовую заявку и убедиться, что письмо пришло. Резервная копия каждой заявки пишется в `zayavki.log` в корне.
5. В Яндекс Вебмастере: добавить сайт, подтвердить регион «Москва», отправить `sitemap.xml` на переобход.
6. Старые адреса перенаправляются автоматически через `.htaccess` (24 правила, см. `redirects.csv`).

## Перед публикацией: заполнить

В `content/company.py` помечены как «ПРОВЕРИТЬ» поля, которые **нельзя придумывать** — их нужно подставить:

| Поле | Что подставить |
|---|---|
| `years` | Год начала работы. Пока пусто — фраза «работаем с … года» не выводится |
| `projects` | Число выполненных проектов |
| `sro` | Номер и название СРО, если есть. Пока пусто — на странице честный текст «предоставим по запросу» |
| `inn`, `ogrn` | Реквизиты. Пока пусто — вместо них «направим по запросу» |
| `metrika` | Номер счётчика Яндекс Метрики. Пока пусто — счётчик не вставляется |
| `REVIEWS` | Реальные отзывы с согласия клиентов. Пока пусто — страница `/otzyvy/` объясняет, почему отзывов нет |
| `CASES` | Обезличенные кейсы. Пока пусто — `/portfolio/` показывает направления и типы объектов |

**Важно:** ни цены по видам работ, ни отзывы, ни кейсы, ни номера лицензий не выдуманы. Цена «от 30 000 ₽» и срок «от 3 дней» взяты с действующего сайта pprpro.ru. Всё остальное, чего у нас нет, страницы обрабатывают честно — без фальшивых цифр.

## Что уже сделано

- 220 страниц, 254 тысячи слов. Медиана — 1 050 слов на страницу, у страниц-категорий 1 500–2 200
- На каждой странице: один H1, несколько H2, несколько H3
- На каждой содержательной странице **три формы заявки**: в первом экране, в середине и в конце; на мобильных — липкая панель «Заказать смету / Позвонить»
- Сквозная перелинковка: 11 331 внутренняя ссылка, битых нет
- Микроразметка Organization, BreadcrumbList, FAQPage
- `sitemap.xml` (220 URL), `robots.txt`, `404.html`, `.htaccess` с 301-редиректами
- Адаптивная вёрстка, без внешних шрифтов и библиотек — грузится быстро и не зависит от заблокированных CDN

## Как добавить страницу

1. Открыть нужный файл в `content/` и добавить запись в список (структура видна по соседним).
2. Запустить `python3 build.py`.
3. Страница появится в `dist/`, в карте сайта и в `sitemap.xml` автоматически.
